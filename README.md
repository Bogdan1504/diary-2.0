# Дневник чтения (Android)

Минималистичный дневник книг: статусы «Читаю», «В планах», «Прочитано», «Брошено», оценки, заметки,
полка с корешками, годовая статистика, импорт из Goodreads (CSV) и любых CSV/JSON, экспорт в JSON и CSV,
поиск книги, обложки и числа страниц в Open Library, сканер ISBN по штрихкоду.
Работает полностью офлайн, данные хранятся на устройстве.

## Как получить APK (без установки Android Studio)

1. Создайте на github.com новый репозиторий (можно приватный).
2. Загрузите в него все файлы из этой папки (включая скрытую папку `.github`).
   Проще всего: распакуйте архив, затем в репозитории нажмите Add file → Upload files и перетащите содержимое.
3. Откройте вкладку **Actions** → **Build APK** → **Run workflow**.
4. Через 4–6 минут откройте завершённый запуск, внизу в блоке **Artifacts** скачайте `reading-diary-apk`.
5. Распакуйте zip, перенесите `app-debug.apk` на телефон и откройте его.
   Android попросит разрешить установку из этого источника.

Это debug-сборка: она подписана отладочным ключом, полностью рабочая, но не для публикации в Google Play.

## Как получить APK локально (если есть Android Studio или JDK 17 и Android SDK)

    npm install
    npx cap add android
    npx cap sync android
    cd android && ./gradlew assembleDebug

Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Обновление приложения

Измените `www/index.html`, загрузите в репозиторий и снова запустите Build APK.
Новый APK ставится поверх старого, книги сохраняются, если подпись та же
(debug-ключ на GitHub Actions каждый раз новый, поэтому перед обновлением сделайте
резервную копию: Ещё → Резервная копия → Сохранить, а после установки импортируйте JSON).

## Обложки и сканер ISBN

- Обложки и страницы берутся из Open Library, нужен интернет. Найденные обложки сохраняются на устройстве
  в уменьшенном виде и дальше показываются офлайн. Русских изданий в Open Library бывает мало, тогда
  данные вводятся вручную. Если в импортированном файле Goodreads есть ISBN, поиск точнее.
- Сканер использует Google Code Scanner (ML Kit). Камеру приложению разрешать не нужно. При первом запуске
  Google Play Services может один раз скачать небольшой модуль сканера. Нужен телефон с Google Play.
- Кнопка «Подтянуть» в разделе Ещё ищет обложки сразу для всех книг без обложки.
- Резервная копия JSON не включает картинки. После восстановления нажмите «Подтянуть», и обложки скачаются заново.

## Поиск по названию и ISBN

Сначала ищется в Open Library, затем (если там мало или ничего) в Google Books: он лучше знает русские издания.
Если книги нет нигде, ISBN сохраняется, остальное вводится вручную.

## Заметки по разделам

В карточке книги пять раскрывающихся разделов: Главные герои, Что случилось, О чем книга на самом деле,
Личные заметки, Цитаты. Заполненные разделы открыты, пустые свёрнуты. В CSV разделы выгружаются в столбец
My Review с заголовками «Главные герои:» и так далее, и при импорте разбираются обратно.
